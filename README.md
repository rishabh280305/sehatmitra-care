# SehatMitra Care

An offline-first healthcare coordination platform for patients, ASHA workers, doctors and hospital teams. Only synthetic demonstration data is permitted.

## Current scope

- Accessible, mobile-first multilingual-ready product shell
- `GET /api/health` with a non-cached server timestamp
- Explicit privacy and non-diagnostic disclaimers

Requires Node.js 22+. Run `npm install`, then `npm run dev`. This application does not claim regulatory compliance and must never contain real patient records.
